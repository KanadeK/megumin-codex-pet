# Character and project research

Research date: **2026-07-30 (Asia/Shanghai)**.

## Selection

The selected existing character is **Megumin / めぐみん / 惠惠** from
*KonoSuba*. This is not an invented character.

Popularity evidence:

- KADOKAWA's official 2019 character election reported Megumin in second place
  with 755,870 points. The voting rules gave Aqua an exceptional 50-point
  option, so the raw point gap should not be treated as a neutral head-to-head
  popularity measurement.
- The official *An Explosion on This Wonderful World!* site makes Megumin the
  named central character and documents the dedicated anime production.

Primary sources:

- <https://www.kadokawa.co.jp/topics/4013/>
- <https://konosuba.com/bakuen/character/>
- <https://konosuba.com/bakuen/staff_cast/>

This is a dated negative-search result, not a permanent uniqueness claim.
Search results can change after publication.

Catalog checked: <https://github.com/legeling/awesome-codex-pet>.

## Functional differentiation

Existing community pet repositories commonly focus on a spritesheet, preview,
and installer. This project adds PetDiff, a reusable atlas-upgrade regression
reviewer:

- deterministic cell and motion snapshots;
- policy budgets with failing exit codes;
- JSON plus self-contained HTML evidence;
- package hardening and reproducibility checks;
- transactional, recoverable lifecycle operations.

The result remains useful to maintainers of other Codex pets even if they do not
install the Megumin asset.

## Rights finding

No broad KADOKAWA fanwork license applicable to this repository was found.
KADOKAWA's current work-use page says unauthorized use of its publications,
video, games, writing, images, manga, music, and other copyrighted works is not
accepted:

<https://www.kadokawa.co.jp/copyrightpolicy/>

Therefore:

- no official source image is committed or used as a generation input;
- the atlas must be an original, non-traced fan-art interpretation;
- code licensing is separated from character and asset rights;
- the repository makes no commercial-use or legal-clearance claim;
- rights holders receive a direct removal/contact path.
